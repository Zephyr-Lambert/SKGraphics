SKGraphics - Rendering resolution reference (SKGraphics 2.0)

HOW TO USE
In SKGraphics.ini, set [Rendering] Enabled=1 and enter Width and Height, or
apply a preset in the in-game menu (F9). Restart the game. These values change
internal rendering, not the desktop resolution. Higher rendering resolution
smooths the final image when it is reduced to the game's output size, at
greater GPU and memory cost.

Use the game's borderless window mode (or windowed mode). Fullscreen is not
supported, and neither is game-level multisampling.

16:9 ONLY
The game always draws a 16:9 picture. On a screen of another shape (a 16:10
Steam Deck or laptop, an ultrawide monitor) it adds black bars around it.
So enter a 16:9 size; it describes the resolution of that 16:9 picture.

On a screen of another shape the mod enlarges the rendering size on one axis
to cover the bars as well, keeping the picture's resolution and the same scale
on both axes. Examples for 3840 x 2160:
  16:9 screen (1920x1080, 2560x1440)    -> 3840 x 2160
  16:10 screen (Steam Deck 1280x800)    -> 3840 x 2400
  ultrawide screen (3440x1440)          -> 5160 x 2160
The log records the fitted size ("Rendering size fitted to output shape").
The bars cost some extra memory and GPU time on those screens.

Accepted values: width 320..16384 and height 180..16384, including after
fitting. Accepted dimensions still require successful resource allocations;
the numeric limit is not a promise that a GPU or runner supports every size.

16:9 SIZES (Width x Height)
  1920 x 1080
  2560 x 1440
  3200 x 1800
  3840 x 2160   (Standard preset)
  5120 x 2880   (High preset)
  6144 x 3456
  7680 x 4320   (Ultra preset)
2560 x 1440 is the Lite preset. Tested: 3840x2160, 5120x2880 and 7680x4320 on
a 2560x1440 output. Any other 16:9 size works the same way: Width = 16 x N,
Height = 9 x N.

SHADOWS ARE SEPARATE
[Shadows] Resolution controls a square shadow map. Its allowed sizes are
1024, 2048, 4096, 8192, 12288 and 16384. The rendering sizes above do not
apply to it.
